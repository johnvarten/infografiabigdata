📚 ¿Qué es un Algoritmo?

Un algoritmo es una secuencia finita de instrucciones lógicas diseñadas para resolver un problema o realizar una tarea específica.

Ejemplo Interactivo: Algoritmo de Búsqueda

ALGORITMO: Encontrar el mayor número INPUT: Lista de números [5, 12, 3, 9, 7] PASO 1: Establecer mayor = primer número (5) PASO 2: Para cada número en la lista: SI número > mayor ENTONCES mayor = número PASO 3: Retornar mayor OUTPUT: 12
Características clave: Finito, Definido, Entrada/Salida clara, Efectivo

🗄️ ¿Qué es Big Data?

Big Data se refiere a conjuntos de datos masivos y complejos que superan la capacidad de procesamiento de herramientas tradicionales.

Las 5 V's del Big Data

📊 Volumen: Petabytes de información
⚡ Velocidad: Datos generados en tiempo real
🎨 Variedad: Estructurados, semi-estructurados, no estructurados
✓ Veracidad: Calidad y confiabilidad de los datos
💎 Valor: Información útil para la toma de decisiones
🧠 Algoritmos en el Análisis de Big Data

Los algoritmos son esenciales para extraer valor de grandes volúmenes de datos.

Tipos de Algoritmos Utilizados

🔍 Machine Learning: Aprenden patrones automáticamente
Ejemplo: Clasificación de emails IF palabras_spam > umbral THEN categoría = "spam" ELSE categoría = "legítimo"
📈 Análisis Predictivo: Predicen tendencias futuras
Ejemplo: Predicción de ventas ventas_futuras = f(historial, temporada, promociones)
🔗 Clustering: Agrupan datos similares
Ejemplo: Segmentación de clientes PARA cada cliente: calcular_similitud(cliente, grupos) asignar_al_grupo_más_cercano()
🌐 Procesamiento Distribuido: MapReduce divide tareas
MAP: Divide datos en nodos → Procesa paralelo REDUCE: Combina resultados → Genera output final
